- title：手机端更新维护说明
 
一、核心前提（首次操作必执行）
 
1. 授予Termux存储权限：
bash
```
termux-setup-storage
````
 
2. 进入Quartz仓库目录：
bash
  

cd /storage/emulated/0/Documents/quartz-showme
 
二、编辑笔记前：同步GitHub最新内容
 
（强制以线上版本为基准，避免本地冲突）
 
bash
  

# 拉取线上main分支最新代码 + 覆盖本地 + 恢复content目录

```
git fetch origin main && git reset --hard origin/main && git checkout origin/main -- content/
chmod -R 755 content/  # 可选：修复content目录读写权限
````
 
三、编辑笔记后：提交更新到GitHub
 
1. 同步本地修改到暂存区：
bash
  

git add content/
 
2. 提交修改（自定义说明）：
bash
  

git commit -m "更新笔记：xxx内容"
 
3. 推送到GitHub线上仓库：
bash
  

git push origin main
 
 
四、验证更新成功
 
打开Quartz网站地址（ https://juanwang01.github.io/quartz-showme/ ），等待1-5分钟后刷新，查看笔记是否已更新。
