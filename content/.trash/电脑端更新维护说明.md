一、前置准备（首次操作）
 
1. 安装Git（官网：https://git-scm.com/ ），并配置GitHub账号：
打开CMD执行：
cmd
  

git config --global user.name "你的GitHub用户名"
git config --global user.email "你的GitHub邮箱"
 
2. 克隆仓库到本地（示例路径： E:\xiangmu\ShowMe\quartz ）：
cmd
  

git clone https://github.com/juanwang01/quartz-showme.git E:\xiangmu\ShowMe\quartz
 
 
二、编辑笔记前：同步GitHub最新content内容（一键脚本）
 
脚本功能
 
仅拉取远程 content 文件夹的最新内容，不影响本地其他文件。
 
操作步骤
 
1. 新建记事本，复制以下代码，保存为 同步笔记.cmd ：
 
cmd
  

@echo off
chcp 65001 >nul
echo 🎯 同步GitHub上content文件夹的最新内容...
cd /d E:\xiangmu\ShowMe\quartz

:: 拉取远程main分支最新代码，仅更新content文件夹
git fetch origin main
git checkout origin/main -- content/

echo ✅ 同步完成！可编辑content文件夹内的笔记
pause
 
 
2. 双击运行 同步笔记.cmd ，等待提示“同步完成”后，即可编辑 content 内的笔记。
 
三、编辑笔记后：上传content修改到GitHub（一键脚本）
 
脚本功能
 
自动提交 content 文件夹的修改，并推送到GitHub线上仓库。
 
操作步骤
 
1. 新建记事本，复制以下代码，保存为 上传笔记.cmd ：
 
cmd
  

@echo off
chcp 65001 >nul
echo 📤 正在上传content文件夹的修改到GitHub...
cd /d E:\xiangmu\ShowMe\quartz

:: 提交content文件夹的修改（自动生成提交信息）
git add content/
git commit -m "更新content文件夹笔记内容（%date% %time%）"

:: 推送到GitHub main分支
git push origin main

echo ✅ 上传完成！GitHub已同步最新笔记
pause
 
 
2. 编辑完笔记后，双击运行 上传笔记.cmd ，等待提示“上传完成”即可。
 
四、验证更新结果
 
1. 打开GitHub仓库的 content 目录，确认文件已更新；
2. 访问Quartz网站： https://juanwang01.github.io/quartz-showme/ ，等待1-5分钟后刷新查看最新笔记。
 
五、常见问题处理
 
1. 同步/上传失败（网络问题）：
重试运行对应的CMD脚本即可。
2. 脚本报错“路径不存在”：
修改脚本中 cd /d 后的路径，与你的本地仓库路径保持一致。
