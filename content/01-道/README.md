# 道

这里是整座知识库的主线：先立世界观，再讲怎么掉下来、怎么回去，最后用观物层和经典原文落地。

「道」把两块内容合在一起：

- **佛法义理**（`01-义理`、`02-观物`）——给出完整的世界图景与心识运行机制；
- **道门经典**（`经`）——《清净经》讲理，《太清元道真经》讲法，与义理互相印证。

## 三条读法

- **初学**：1 → 5 → 6。先拿到世界图景，再补原理细节。
- **弄懂原理**：1 → 2 → 4。把两条逻辑主线完整走一遍。
- **准备实修**：1 → 2 → 3 → 7 → 8。理路清楚后直接落到功课。
