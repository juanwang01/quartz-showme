# 八字命理基础概念与技术框架

## 一、什么是八字

八字 = 四柱（年柱、月柱、日柱、时柱），每柱一个天干+一个地支，共八个字。

```
年柱（壬午）→ 祖上、父母、童年 0-16岁
月柱（癸卯）→ 事业、兄弟、外部环境 17-32岁
日柱（己丑）→ 自己（天干）+ 配偶（地支） 33-48岁
时柱（戊辰）→ 子女、晚年 49岁+
```

日柱的天干（日干/日主/日元）代表你自己。本命局日干是 **己土**，一切分析围绕己土展开。

## 三、五行生克

```
相生：木→火→土→金→水→木（循环）
相克：木克土、土克水、水克火、火克金、金克木
```

本命局的核心生克链路：

```
水（壬癸）→ 生 → 木（卯）→ 克 → 土（己）
                  ↑ 化解                ↓
              火（午）←------------- 通过火化杀
```

**翻译成白话：** 水是你的财、欲望、压力源；水去生木（七杀），七杀来克你；唯一的救星是火，火能泄木（化解）又能暖土（生你）。所以火 = 命局的救命药。

## 五、格局

格局由月令（月柱地支）决定，是命局的「底色」。

- 月令是什么五行 → 定格局
- 格局决定人生主线任务

本命局：**卯月 → 卯=乙木 → 乙木克己土（七杀关系）→ 七杀格**

七杀格的人：天生需要对抗、突破、承受压力。不适合平庸安稳的路线。七杀格的成就上限极高，但前提是有"制化"（本命局的制化=火来化杀）。

## 六、宫位

四柱每柱分三部分：

| 柱     | 年龄段    | 人事宫位        | 身体部位 |
| ----- | ------ | ----------- | ---- |
| **年** | 0-16岁  | 祖上、父母、早年    | 头、颈  |
| **月** | 17-32岁 | 事业、兄弟、外部    | 胸、肩  |
| **日** | 33-48岁 | 自己（干）、配偶（支） | 腹、腰  |
| **时** | 49岁+   | 子女、晚年       | 腿、足  |

**关键认知：**

- 每柱是天干+地支的整体，不是只看地支
- 宫位和十神是两个维度。比如月柱癸卯 → 宫位=事业宫，十神=偏财坐七杀 → 事业环境自带"高回报+高压"属性
- 同一个地支可能承载多个角色。比如卯木：它在月柱=事业宫地支，它是七杀=格局星，它还是桃花（子午卯酉四桃花之一）

## 七、大运与流年

### 7.1 大运

- 大运是十年一换的"季节"，决定这个阶段的整体气候
- 从月柱推导而来：男命阳年生顺排，阴年生逆排
- 本命局生于壬午年（阳年），男命，顺排大运
- 起运年龄：出生后 4年7个月26天 → 约5岁起运

**大运的读法：** 大运干支是一个整体。天干管前五年侧重，地支管后五年侧重，但两者始终相互影响。

### 7.2 流年

- 每年一个干支，叠加在大运上
- 流年 + 大运 + 原局 = 三层互动

### 7.3 岁运命三层叠加

```
原局四柱（不变的底座）
    +
大运干支（十年的背景色）
    +
流年干支（今年的具体事件）
    =
今年的实际运势
```

## 八、地支的刑冲合害

地支之间不是孤立的，它们会发生关系：

### 8.1 六合（和谐、吸引）

```
子丑合 寅亥合 卯戌合 辰酉合 巳申合 午未合
```

### 8.2 六冲（冲突、变动）

```
子午冲 丑未冲 寅申冲 卯酉冲 辰戌冲 巳亥冲
```

冲 = 动，不一定都是坏。财库被冲开也可能是暴富。

### 8.3 三合局（强力的三方联盟）

```
申子辰→水局  亥卯未→木局  寅午戌→火局  巳酉丑→金局
```

### 8.4 相穿/害（暗中破坏）

```
子未穿 丑午穿 寅巳穿 卯辰穿 申亥穿 酉戌穿
```

穿比冲更难防，因为是暗中的、长期的摩擦。

### 8.5 相破（轻微的破坏）

```
子酉破 寅亥破 辰丑破 午卯破 申巳破 戌未破
```

### 8.6 自刑（自己给自己找麻烦）

```
辰辰自刑 午午自刑 酉酉自刑 亥亥自刑
```

### 本命局的地支互动一览

```
午（年）-- 午午自刑 --> 与丙午大运伏吟
  ├── 丑午穿（与日支，配偶宫被穿）
  └── 午卯破（与月支）

卯（月）-- 卯辰穿（与时支）
  └── 卯戌合（逢戌年）

丑（日）-- 丑午穿（与年支）
  ├── 丑辰破（与时支）
  └── 丑未冲（逢未年，冲开财库）

辰（时）-- 辰卯穿（与月支）
  ├── 辰丑破（与日支）
  └── 辰戌冲（逢戌年，冲开财库）
```

## 九、神煞

神煞是附加在干支上的特殊标记，类似于"buff/debuff"。不是主线但能提供细节。

### 本命局神煞一览

| 神煞 | 位置 | 含义 |
|------|------|------|
| **天乙贵人** | 卯（月支） | 最大的吉星，关键时刻有贵人保底 |
| **太极贵人** | 丑（日）、辰（时） | 对复杂系统、玄学、逻辑有天生的直觉 |
| **华盖** | 丑（日） | 孤傲、才华、喜独处钻研 |
| **将星** | 午（年） | 管理基因、领导才能 |
| **德秀贵人** | 年柱 | 品行端正、有文化底蕴 |
| **驿马** | 辛亥大运 | 出行、迁移、远方 |

### 桃花（咸池）查法

桃花不是「子午卯酉四个都算桃花」，而是**以年支或日支为基准**，按口诀查找：

| 基准 | 口诀 | 桃花位 |
|------|------|--------|
| 申、子、辰 | 申子辰见酉 | **酉** |
| 寅、午、戌 | 寅午戌见卯 | **卯** |
| 巳、酉、丑 | 巳酉丑见午 | **午** |
| 亥、卯、未 | 亥卯未见子 | **子** |

**年柱桃花 vs 日柱桃花：**

| 查法 | 代表含义 |
|------|---------|
| **年支查** | 先天家族桃花、早年人缘、长辈赏识 |
| **日支查**（更常用） | 本人内在魅力、配偶婚姻、夫妻宫桃花 |

**桃花所在柱位含义：**

| 柱位 | 含义 |
|------|------|
| 年柱 | 早年缘好、长辈赏识 |
| 月柱 | 青年/中年旺、社交广、职场异性助力 |
| 日柱（日坐桃花） | 自身魅力强、配偶貌美 |
| 时柱 | 晚年缘、晚辈缘 |

**本命局桃花核查（年支午 + 日支丑）：**

```
年支午 → 寅午戌见卯 → 桃花在卯（月支）→ 月柱桃花
日支丑 → 巳酉丑见午 → 桃花在午（年支）→ 年柱桃花（日支引动）
```

两个桃花都入命：青年桃花在事业环境（月支卯），且配偶宫（日支丑）引动了年柱桃花（午）→ 配偶与早年缘分有呼应。

**注意：桃花管感情机缘的时机和人际魅力，配偶质量本身要看日支。**

## 十、喜忌

喜忌是对日主（己土）有利/有害的五行。

### 10.1 判断依据

- 日主强弱（身强 → 喜克泄耗；身弱 → 喜生扶）
- 格局需求（七杀格 → 喜制化）
- 寒湿燥湿（寒湿 → 喜火暖局）

### 本命局喜忌定论

| 类别 | 五行 | 具体干支 | 原因 |
|------|------|---------|------|
| **最喜** | 火 | 丙丁午巳 | 化杀（泄木）、暖局（去湿）、制水、生身 |
| **次喜** | 燥土 | 戊戌 | 制水断杀源、帮身扛压、不增寒湿 |
| **头号忌** | 木 | 甲乙卯寅 | 七杀克身，压力焦虑源头 |
| **二号忌** | 水 | 壬癸亥子 | 财生杀、加重寒湿 |
| **偏忌** | 金 | 庚辛申酉 | 生水助忌、泄土耗身 |
| **中性偏忌** | 湿土 | 己丑辰 | 帮身但自带水气，越堆越湿 |

## 十一、寒湿燥湿（理气论）

五行之外还有气候维度：

- **寒暖：** 生于冬→寒，生于夏→暖
- **燥湿：** 土分燥（戌未）湿（辰丑），水多则湿

本命局生于卯月（仲春），余寒未消 + 壬癸水双透 + 丑辰湿土叠见 → **典型的寒湿命局**。

寒湿的直接后果：
- 想法多、落地少（湿气淤塞，行动力被闷住）
- 脾胃易虚（土过湿）
- 情绪易低沉（缺阳光）
- 才华难以变现（火弱，没热力推动）

火运（丙午、丁未）就是"点火烘土"，寒湿一去，执行力自然到位。

## 十二、技术分析的四步法

贯穿所有维度的通用方法论：

```
第一步：原局定基调
→ 看命盘本身告诉你什么（一生不变的上限下限）

第二步：大运定节奏  
→ 看这十年是什么季节（进攻还是防守）

第三步：流年定节点
→ 看今年具体发生什么（升职/破财/结婚/生病）

第四步：神煞+喜忌给细节和方向
→ 往哪走，避开什么，用什么方式应对
```

对每个具体维度的分析（事业、财运、姻缘等），在这个通用框架之上叠加该维度特有的十神/宫位/五行信号即可。

## 附录：常用术语速查

| 术语 | 含义 |
|------|------|
| 透干 | 天干上出现了（力量大，外显） |
| 藏支 | 藏在地支里（力量小，内隐） |
| 盖头 | 天干压住地支（如壬午=壬水盖午火） |
| 截脚 | 地支克天干 |
| 当令 | 月令正好是这个五行（力量最大） |
| 得地 | 地支有同类支持 |
| 身强/身旺 | 日主力量强，能担财官 |
| 身弱 | 日主力量弱，需帮扶 |
| 用神 | 对日主最有利的五行（药） |
| 忌神 | 对日主最不利的五行（病） |
| 伏吟 | 干支重复出现（如丙午大运遇丙午年） |
| 反吟 | 干支天克地冲（如丙午遇壬子） |
| 岁运并临 | 流年干支 = 大运干支（吉凶加倍） |

| 通关 | 在相克两方之间加入中介（如火在木土之间通关） |
