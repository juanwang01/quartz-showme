# 2025年度工作总结

## 一、工作概述

2025年是我从事中药材质量检测工作的重要一年。本年度工作以 HPLC 色谱分析为核心，严格按照《中国药典》标准对各类中药材及成品进行质量检测，确保产品质量符合国家标准。

### 2.3 检测项目

- **含量测定**：各类有效成分含量检测
- **特征图谱**：天麻等中药材的特征图谱分析
- **对照品配制**：各类标准对照品溶液的精确配制
- **样品前处理**：称量、提取、稀释等

## 三、工作内容详解

### 3.1 日常工作流程

每日工作遵循标准化流程：

```
1. 样品制备（称量、提取）
2. 对照品配制
3. HPLC 仪器设置（方法设置 → 流动相 → 样品放置 → 序列设置）
4. 样品检测
5. 图谱处理
6. 记录撰写
```

### 3.2 典型检测案例

**天麻检测**：
- 含量测定：平行双样，称样量约 2.2g
- 特征图谱：称样量约 0.5-0.8g
- 对照药材处理：约 0.5g

**浙贝母检测**：
- 对照品：贝母素甲 0.2mg/ml、贝母素乙 0.15mg/ml 混合溶液
- 样品称样量：约 2g

**酸枣仁检测**：
- 对照品：斯皮诺素 0.2mg/ml
- 样品称样量：约 1g

## 四、工作亮点与成果

### 4.1 工作记录规范化

建立了一套完善的每日工作记录模板：
- 待办事项清单（要跑的成品、要做的样品、要处理的图谱、要写的记录）
- 样品信息详细记录（名称、批号、称样量）
- 对照品配制计算过程记录
- 检测结果汇总

### 4.2 实验操作严谨

- 所有样品均进行平行双样检测
- 对照品配制过程记录完整，包含纯度校正
- 称样量精确到 0.0001g
- 严格按照药典标准执行

### 4.3 持续学习能力

全年检测品种丰富，涉及多种中药材的不同检测方法，展现了良好的专业适应能力和学习能力。
