# 现在是2025年11月27日，

我计划这个周末去菜市场买泥鳅，大概两百块钱活的，然后放生到青白江大河里面，所以最好是青白江大河附近的菜市场买。


# 2025年11月30日

去菜市场买泥鳅，12元一斤，全包一共10斤，花费120元外加一个水桶10元合计130元

放生地点青白江大河
![](https://raw.gitcode.com/qq_57305183/PicGo/raw/main/fangshen1.jpg)


经验总结：

放生后泥鳅会一蹶不振，需要缓很久才能缓过来，重新适应新环境。

放生应该多点放生，太密集了就会很显眼，散不开容易被钓鱼佬发现。

观察周围避开钓鱼佬。

我觉得应该在活水里面放好些，这人散的更快。

# 2025年12月7日

今天是星期天，放一天假，这次消费15块，到镇子上的渔具店买了5袋子。

蚯蚓，放生地点是路边的树林中，蚯蚓的状态和之前放生的泥鳅状态一样都不好。

这是放生时的照片

这是掩埋后的样子

旁边就是钓鱼佬，但是没有被发现。

在渔具店购买的时候我就在想，这些蚯蚓如果我不买，他们能不能顺利活到老死，结果我放生的时候打开看，里面蚯蚓都半死不活的状态了，状态很差。

我只买了五包，但他那里还有一箱子。
