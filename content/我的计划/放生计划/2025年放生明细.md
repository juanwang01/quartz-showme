# 现在是2025年11月27日，

我计划这个周末去菜市场买泥鳅，大概两百块钱活的，然后放生到青白江大河里面，所以最好是青白江大河附近的菜市场买。


# 2025年11月30日

去菜市场买泥鳅，12元一斤，全包一共10斤，花费120元外加一个水桶10元合计130元

放生地点青白江大河
![](https://raw.gitcode.com/qq_57305183/PicGo/raw/main/fangshen1.jpg)


经验总结：

放生后泥鳅会一蹶不振，需要缓很久才能缓过来，重新适应新环境。

放生应该多点放生，太密集了就会很显眼，散不开容易被钓鱼佬发现。

观察周围避开钓鱼佬。

我觉得应该在活水里面放好些，这人散的更快。

# 2025年12月7日

今天是星期天，放一天假，这次消费15块，到镇子上的渔具店买了5袋子。

蚯蚓，放生地点是路边的树林中，蚯蚓的状态和之前放生的泥鳅状态一样都不好。

这是放生时的照片
![](https://raw.gitcode.com/qq_57305183/PicGo/raw/main/fangshen2-1.jpg)




这是掩埋后的样子
![](https://raw.gitcode.com/qq_57305183/PicGo/raw/main/fangshen2-2.jpg)

旁边就是钓鱼佬，但是没有被发现。

在渔具店购买的时候我就在想，这些蚯蚓如果我不买，他们能不能顺利活到老死，结果我放生的时候打开看，里面蚯蚓都半死不活的状态了，状态很差。

我只买了五包，但他那里还有一箱子。
# 2025年12月14日

这次依然放生的是蚯蚓，选择地点可能不太理想，但是买的蚯蚓自带环境，并且已经做了放生仪轨。

在做放生仪轨的时候有一只小虫子从草堆里面爬出来，翻山越岭来到我的面前的那个草的上面！！？

他爬出来的时候我还没注意，知道他爬到我面前来，听我念完了三皈依。


# 2025年12月20日

参见了一个18万的项目，救助皮毛商养的狐狸等，虽然我只出了100块，有救助现场反馈


2025年12月20日在泰安开展了狐狸、貉子、水貂、狗、鸡、鸭、鹅等动物的营救行动，此次善款总计235248元，分为救生款和护生款两部分：
 
1. 救生款：合计180960元，向三家商家采购动物产生费用。第一家花费38500元（狐狸101只、貉子61只、狗7只）；第二家花费37160元（狐狸117只、貉子25只、母水貂15只、公水貂5只）；第三家花费105300元（狐狸57只、貉子519只、狗26只、鸡11只、鸭18只、鹅5只）。
2. 护生款：由石家庄欢喜护生基地接收，按救生款的30%核算，金额为54288元。
