# 生命质量审计问卷

> 本问卷通过8大参数的采集，计算您的生命真实质量TBI值

---

## 使用说明

1. **如实填写**：只有如实回答才能获得真实结果
2. **分模块计算**：每个模块完成后可先计算该参数值
3. **最终汇总**：将所有参数代入主公式计算TBI

---

## 第一部分：硬件模块（H参数）

### H1：医学指标
您目前的医学检查情况是？
- [ ] A. 患有危及生命的重疾（癌症/脏器坏死/需长期服药）→ H ∈ [0, 2.9]
- [ ] B. 指标异常：确诊有结节、息肉、囊肿、慢性炎症 → H ∈ [3.0, 4.4]
- [ ] C. 指标完全正常 → 继续H2

### H2：主观体感（无病症时）
在无病症前提下，您的日常感受是？
- [ ] A. 良好：身体轻灵，精力充沛 → 继续H3
- [ ] B. 不得劲：容易累，睡不醒，身体沉重 → H ∈ [4.5, 5.9]

### H3：呼吸频率
请静坐并数一分钟呼吸（一吸一呼为1次）：
- [ ] A. 26次及以上 → H ≤ 3.4（隐性病态）
- [ ] B. 21-25次 → H ∈ [4.5, 5.9]（亚健康预警）
- [ ] C. 15-20次 → H ∈ [6.0, 7.4]（普通健康）
- [ ] D. 10-14次 → H ∈ [6.0, 7.4]（巅峰常态）
- [ ] E. 5-9次 → 继续H4
- [ ] F. 5次以下 → 继续H4

### H4：修行校验（呼吸<10次者必填）
**A. 饮食**：是否已完全断肉（全素）？
- [ ] 是
- [ ] 否 → H封顶7.4

**B. 双盘**：您目前的双盘极限时长？
- [ ] 1. 无法双盘或少于1小时 → H ∈ [7.1, 7.4]
- [ ] 2. 2小时以上（不剧痛，无妄想）→ H ∈ [7.5, 8.9]
- [ ] 3. 4小时以上（进入坐忘）→ H ∈ [9.0, 10.0]

**【通用】**

### Φ3：硬件损耗
