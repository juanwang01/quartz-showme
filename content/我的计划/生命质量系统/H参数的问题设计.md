## 🛠️ 第二部分：采集逻辑与算法权重

### 1. 硬件层 (优先级最高)

- **规则**：若有病（结节/息肉/重疾），呼吸频率不再作为定级依据，仅作为严重程度参考。
    
- **分级**：有轻症封顶 4.4，有重症封顶 2.9。
    

### 2. 能效层 (呼吸频率分段)

- **RR > 25**：强制判定为 $H \le 3.4$ (即便主观无感，也判定为隐性病态)。
    
- **RR 18-25**：结合体感。体感良好为 6.0，体感不得劲为 4.5-5.9。
    
- **RR 10-18**：普通健康区间。
    
- **RR < 10 (即 5-9次 及 5次以下)**：**【强制触发修行选项】**。如果呼吸低于10次但无法双盘或未断肉，系统判定为数据异常或短时强行憋气，降级处理。
    

### 3. 修行层 (上限解锁)

- **逻辑**：只有呼吸 < 10次 且 满足 [断肉] + [双盘时长] 两个硬性指标，才能越过 7.4 的凡夫天花板。

## 🏁 审计结论生成逻辑 (后台伪代码)

1. **if** (有病症) **then** $H = \text{病症等级}$；
    
2. **else if** ($RR < 10$) {
    
    **if** (双盘 $\ge 4h$ && 断肉) $H = 9.0-10.0$ (绝对健康)；
    
    **else if** (双盘 $\ge 2h$ && 断肉) $H = 7.5-8.9$ (入静健康)；
    
    **else** $H = 7.1-7.4$ (修行起步)；
    
    }
    
3. **else** {
    
    **if** (体感不得劲) $H = 4.5-5.9$ (亚健康)；
    
    **else** $H = 6.0-7.4$ (普通健康)；
    
    }
