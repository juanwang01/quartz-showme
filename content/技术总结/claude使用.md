#危险模式
## 📖 Claude Code 实战全指南

### 一、 基础入门与环境配置

- **安装命令**：直接在终端粘贴官方复制的安装脚本即可 。
    
- **登录方式** ：
    
    - **订阅制**：支持 Claude Pro 或 Max 会员。
        
    - **按量计费**：使用官方 API Key，按 Token 用量扣费。
        
    - **国产模型驱动**：通过设置环境变量，可接入 GLM、Minimax 等国产大模型 。
        
- **常用命令**：
    
    - `cloud`：在当前目录启动工具 。
        
    - `cloud -c` 或 `cloud --resume`：恢复上一次的对话会话 。
        

### 二、 核心操作模式 (Shift + Tab 切换)

Claude Code 的精髓在于其三种交互模式，分别应对不同的开发阶段 ：

1. **默认模式 (Default)**：最稳妥。每次创建或修改文件前，都会询问用户授权 。
    
2. **自动模式 (Accept Edits On)**：最方便。后续文件操作自动通过，适合快速迭代 。
    
3. **规划模式 (Plan Mode)**：最严谨。只讨论方案、构思架构，不实际修改代码 。
    

---

### 三、 进阶开发技巧

- **终端控制 (Bash Mode)**：输入 `!` 即可直接运行终端命令（如 `!open index.html`） 。
    
- **全自动高能模式**：启动时添加 `--dangerously-skip-permissions` 参数，Claude 将跳过所有权限检测（包括终端执行），实现全自动干活，但需注意安全风险 。
    
- **VS Code 联动**：按 `Ctrl + g` 可打开 VS Code 编辑器页签，用于编写复杂的 Prompt 或长文需求 。
    
- **后台任务管理**：
    
    - `Ctrl + b`：将运行中的服务（如 `npm run dev`）挂起至后台，避免阻塞对话 。
        
    - `/tasks`：查看当前运行的后台任务，按 `k` 可结束任务 。
        

---

### 四、 复杂任务与多模态处理

- **回滚功能 (`/rewind` 或双击 `ESC`)**：
    
    - 支持“只回滚代码”、“只回滚对话”或“两者都回滚” 。
        
    - **注意**：它只能回滚 Claude 自己写入的文件，无法撤销由终端命令生成的文件（如 `npm install` 产生的 `node_modules`） 。
        
- **多模态：图片转代码**：
    
    - 直接将设计稿截图拖入终端，或使用 `Ctrl + v` 粘贴（Mac 下也是 `Ctrl + v`） 。
        
- **Figma 联动 (MCP)**：
    
    - 通过安装 Figma MCP Server，Claude 可以直接获取设计稿的组件间距、字体、样式等精确信息，实现高还原度开发 。
        

---

### 五、 高级扩展与知识库管理

- **上下文压缩 (`/compact`)**：清空琐碎过程，只保留核心需求和结果，既能提升响应速度，又能节省 Token 。
    
- **项目记忆文件 (`claude.md`)**：
    
    - 通过 `/init` 创建。Claude 每次启动都会读取此文件 。
        
    - 适合存放项目规范、技术栈要求、全局注意事项（如“必须使用 TypeScript”） 。
        
- **自动化 Hook**：
    
    - 通过 `/hooks` 配置。例如在 `write/edit` 工具执行后自动运行 Prettier 进行代码格式化 。
        

---

### 六、 Agent 实战：Skill 与 Sub-agent

|**功能**|**独立上下文**|**适用场景**|
|---|---|---|
|**Agent Skill**|共享主对话上下文|适合处理与当前项目关联度高的小任务（如写每日总结） 。|
|**Sub-agent**|完全独立的上下文|适合处理大规模、高消耗的任务（如大型代码审核），避免主对话被琐碎日志填满 。|

- **Plugin (插件)**：由 Skill、Sub-agent 和 MCP 工具组成的“全家桶”，如 `frontend-design` 插件可赋予 Claude 更高级的 UI 审美和设计直觉 。
