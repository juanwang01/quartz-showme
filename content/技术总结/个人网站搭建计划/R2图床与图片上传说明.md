# R2 图床与图片上传说明

## 为什么要有图床

三个原因，都很实在：

1. **手机端传不了大图**。手机上写作顺手，但截图、导出图的整理和上传很难受，所以干脆不让手机管图。
2. **仓库和构建要轻**。400 多张易学插图如果放在 vault 里，坚果云要同步、服务器要镜像、git 要存、Quartz 要拷进 `public/`，每一步都变慢。
3. **加载速度**。R2 走 Cloudflare CDN，图片比从 GitHub Pages 拉快得多，也不占 Pages 的带宽和仓库配额。

当前状态（2026-11-22 完成迁移）：

- 图床域名：`img.longbatian.site`
- 已迁移 **415 张图片 + 1 张总架构图**，笔记里统一改成绝对直链
- **本地图片副本已删除**，`Z-附件` 目录清空

## 现在的路径与命名约定

```text
https://img.longbatian.site/btwy/4rSKg5FW.jpg
                        └─┬──┘ └───┬───┘
                       主题前缀   文件名
```

- **主题前缀**：目前只有一个 `btwy/`（霸天玩易）。新增主题时用新的短前缀，例如 `jishu/`、`sushi/`、`rwsg/`，便于整批管理和排查。
- **文件名**：迁移时用的是 8 位随机串（`4rSKg5FW.jpg`），好处是永不重名、不会被覆盖；坏处是看名字认不出内容。以后手工上传更推荐 `主题-章节-序号-要点` 这种可读命名，例如 `btwy/07-地支藏干-01-藏干对照表.png`。
- **扩展名**：现在库里 321 张 jpg、99 张 png。截图优先 png，照片优先 jpg，别用 webp/gif（兼容性和体积的平衡）。

## 笔记里怎么写

### 普通插图

```markdown
![](https://img.longbatian.site/btwy/xxxx.png)
```

### 带图注、要控制宽度（易学章节用的就是这种）

```markdown
> **图 1**<br><img src="https://img.longbatian.site/btwy/fix007.jpg" width="380" alt="fix007">
```

- `width` 建议只有几档：`380`（竖图/小图）、`860`（横图/大图），统一才好看。
- `alt` 写图的内容摘要，利于无障碍和搜索。
- 想点击放大（灯箱）就保持现在的写法，站点已有灯箱效果：点图放大、滚轮缩放、Esc 退出。

## 上传流程（只能在电脑端）

> [!warning] 手机端不能上传
> 手机端只负责写文字、留占位符。图片上传一律回电脑做。

流程：

1. 把图片集中放到电脑上一个临时目录（别放进 Obsidian 库）。
2. 上传到 R2，二选一：
   - **跑脚本**：本地已有上传脚本，指定目录和主题前缀即可；
   - **让 AI 传**：把目录和前缀告诉电脑端的 AI，让它调用上传脚本/工具完成后回你一份「本地文件 → 直链」对应表。
3. 拿到直链后替换笔记里的占位符（`![](待补图-xxx)` 或 `> TODO 补图：xxx`）。
4. 确认线上图片能打开（`img.longbatian.site/...` 返回 200）。
5. **删掉本地图片副本**，保持库干净。

> [!tip] 记录一次真实调用
> 本地脚本的具体命令、参数、密钥位置还没写进文档。下次上传图片时把实际用的命令补到这一节，以后就能无脑复制。

## 排错

| 现象 | 原因 | 处理 |
|---|---|---|
| 图片 404 | 对象没上传成功 / 路径或大小写写错 / 前缀目录不对 | 回 R2 控制台看对象是否存在，再核对 URL |
| 图片能存但浏览器不显示 | 对象没开公开访问，或 CDN 缓存未刷新 | 检查 bucket 公开访问与自定义域绑定，必要时刷缓存 |
| Obsidian 里显示不出来、网站正常 | Obsidian 没开「显示外部图片」或网络问题 | 属正常，可忽略 |
| 中文文件名打不开 | URL 未编码 | 改用英文/数字命名，最稳 |
| 图片被覆盖后内容变了 | 同名上传 | 新图用新文件名，不要复用旧名字 |

## 常见问题

### 可以把 R2 里的图删掉吗？

可以，但**所有引用它的笔记都会裂图**。删之前先全库搜文件名：

```bash
rg -n 'fix007.jpg' --glob '*.md'
```

### 换图床域名要做什么？

全库替换：`rg -l 'img\.longbatian\.site' --glob '*.md'` 找出所有文件 → 批量替换域名。所以**写死绝对直链是有代价的**，换域名时是一次全库手术。

### 图片应该多大？

- 截图：宽度 800–1600px 足够，别传 2K 原图。
- 手机拍照：先缩到长边 1600px。
- 体积目标：单张 < 500KB。超过 1MB 的图先压再传。

### R2 会花钱吗？

有免费额度，个人站点的图片量在这个量级基本碰不到付费线。真正的风险是「图片无限增长 + 每张都几 MB」，所以上传前压一下。
