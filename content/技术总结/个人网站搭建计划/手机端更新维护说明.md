> [!info] 使用环境
> 本指南适用于在 Android 设备上使用 Termux 和 Git 管理 Obsidian 笔记的用户。

## 🚀 准备工作

> [!warning] 前提条件
> 在开始之前，请确保已安装并配置好 Termux 和 Git。

### 1. 初始化存储权限
```bash
termux-setup-storage
```

### 2. 进入项目目录
```bash
cd /storage/emulated/0/Documents/quartz-showme
```

## 📱 编辑笔记流程

### 一、编辑前：同步最新内容

> [!tip] 建议每次编辑前都执行此步骤
> 确保本地内容与 GitHub 仓库保持同步，避免冲突。

```bash
git pull
```

### 二、编辑后：提交并推送修改

```bash
# 添加修改的文件
git add content/
```

```bash
git commit -m "更新内容"
```

```bash
git push origin main
```

## 🔧 故障排除

### 上传失败解决方案

```bash
# 查看本地分支超前远端的提交数量
git rev-list --count origin/main..main

# 若输出数字大于 0，直接推送
git push origin main
```

### 三、SSH 推送失败（一次性配置）

> [!note] SSH 配置
> 如果遇到 SSH 连接问题，请按以下步骤配置。

#### 1. 创建 SSH 配置文件
```bash
mkdir -p ~/.ssh && nano ~/.ssh/config
```

在 nano 编辑器中粘贴以下内容：
```
Host github.com
    Hostname ssh.github.com
    Port 443
    User git
    IdentityFile ~/.ssh/id_rsa
```

保存并退出：
- 按 `Ctrl+O` → 回车 → `Ctrl+X`

#### 2. 修复 SSH 配置权限
```bash
chmod 700 ~/.ssh && chmod 600 ~/.ssh/config && chmod 600 ~/.ssh/id_rsa
```

#### 3. 测试 SSH 连接
```bash
ssh -T git@github.com
```

预期输出：`Hi username! You've successfully authenticated...`

1. **定期同步**：建议每天至少同步一次
2. **提交信息**：使用有意义的提交信息，方便追踪
3. **备份重要数据**：重要笔记建议本地备份
4. **网络环境**：确保在稳定的网络环境下进行同步操作
