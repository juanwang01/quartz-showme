一、编辑笔记前：同步 GitHub 最新内容
 ```
```bash
# 强制同步：以GitHub线上为基准覆盖本地content
git fetch origin main && git reset --hard origin/main && git checkout origin/main -- content/
chmod -R 755 content/  # 可选：修复权限
echo "✅ 同步完成，可打开 Obsidian 编辑笔记"
```
`` 
 
 
二、编辑笔记后：提交并推送修改


 ```
git add content/
if ! git diff --cached --quiet; then
git commit -m "手机端 Obsidian 同步笔记：$(date '+%Y-%m-%d %H:%M:%S')"
git push origin main
echo "✅ 笔记已成功推送到 GitHub"
else
echo "⚠️  没有检测到笔记修改，无需提交"
fi
````

上传失败解决办法：

```
#查看本地分支超前远端的数量
git rev-list --count origin/main..main
#若输出数字大于 0，直接推送
git push origin main
 
 ````
 
三、解决 SSH 推送失败（一次性配置）
 
 1. 创建 SSH 配置文件
 ```
mkdir -p ~/.ssh && nano ~/.ssh/config
（粘贴内容：Host github.com Hostname ssh.github.com Port 443 User git IdentityFile ~/.ssh/id_rsa）
（保存：Ctrl+O → 回车 → Ctrl+X）
````
2. 修复 SSH 配置权限
```
chmod 700 ~/.ssh && chmod 600 ~/.ssh/config && chmod 600 ~/.ssh/id_rsa
````
3. 测试 SSH 连接
```
ssh -T git@github.com
````
