# 第五章 梅花新易预测法

## 第一节 主卦、互卦、变卦及动爻的表示方法

### 一、卦的组成

一个卦是由上下两个经卦（也叫单卦）组成，读卦时自上而下

| 术语 | 说明 |
|:---:|:---|
| **上卦（外卦）** | 在卦的上边的经卦叫做上卦，也叫做外卦 |
| **下卦（内卦）** | 在下边的经卦叫下卦也叫内卦 |
| **动爻** | 卦中的任意一个发生变化的爻称作动爻 |
| **体卦** | 卦中没有动爻的经卦，体卦代表求测人，代表事物的主体 |
| **用卦** | 卦中有动爻的经卦，用卦代表对方，代表事物的外在条件 |

### 二、主卦、互卦、变卦（也称之卦）

| 术语 | 定义 |
|:---:|:---|
| **主卦** | 用任意方法起的卦，没发生动变之前的卦 |
| **互卦** | 互卦是由主卦的二、三、四爻组成下卦，三、四、五爻组成上卦。写卦时自下而上。读卦时自上而下 |
| **变卦（之卦）** | 由于主卦中的任意一个爻发生变化而组成的卦 |

## 第二节 梅花新易的起卦方法

### 一、时间起卦法

#### 方法1：按年、月、日、时数来计算

**年序数表**

| 地支 | 序数 |
|:---:|:---:|
| 子 | 1 |
| 丑 | 2 |
| 寅 | 3 |
| 卯 | 4 |
| 辰 | 5 |
| 巳 | 6 |
| 午 | 7 |
| 未 | 8 |
| 申 | 9 |
| 酉 | 10 |
| 戌 | 11 |
| 亥 | 12 |

**计算方法：**
- 上卦 = (年+月+日) ÷ 8，余数作上卦
- 下卦 = (年+月+日+时) ÷ 8，余数作下卦
- 动爻 = (年+月+日+时) ÷ 6，余数作动爻

#### 方法2：按当时的时间起卦

- 上卦：时针数（超过8用8除）
- 下卦：分针数（超过8用8除）
- 动爻：(时针数+分针数) ÷ 6

### 二、来人报数起卦

- 第一个数为上卦
- 第二个数为下卦
- 第三个数为动爻

## 第三节 梅花新易的体用学说

### 一、梅花新易的"体""用"分辨

- **体**：事物的主体，为自己，为测卦人，为所测之事的主流
- **用**：他人，为对方，为事物外因对体的作用关系

### 二、梅花新易的互卦之说

互卦表示事物的中间过程与不为人知之隐秘之事

| 术语 | 别称 |
|:---:|:---|
| 体互 | 外互、上互 |
| 用互 | 内互、下互 |

### 三至六、体用关系

| 关系类型 | 说明 |
|:---|:---|
| **体用相生** | 体用是五行相生的关系 |
| **体用帮扶** | 体用是相同的五行关系，又互为阴阳 |
| **体用相克** | 体用的五行相克 |
| **体用比和** | 体卦与用卦为同一种五行重叠的卦，也叫八纯卦 |

## 第四节 梅花新易的体用互变的内在关系

### 一、梅花新易的体用生克定吉凶

| 关系 | 结果 |
|:---|:---|
| 用卦生体卦 | 吉利，事易成，有进益之喜 |
| 体卦生用卦 | 耗泄之患，诸事难成 |
| 体卦克用卦 | 次吉，费力可成功 |
| 用卦克体卦 | 凶，诸事不顺 |
| 体卦用卦比和 | 诸事顺利 |

### 二、梅花新易诸卦论六亲

| 卦位 | 代表 |
|:---|:---|
| 主卦的体卦 | 自己 |
| 主卦的用卦 | 配偶、出生环境 |
| 变卦的用卦 | 子女 |
| 互卦 | 不为人知之事或中间过程 |

**阴阳性别规则：**
- 用卦的阳性经卦：父亲
- 用卦的阴性经卦：母亲

## 第五节 梅花新易直读法

### 一、梅花新易的数字直读法

#### 1. 只测单一数主卦直接读

根据卦数直接自上而下或自下而上读出数字

#### 2. 带有艮土的卦在上卦读最多，在下卦读最少

#### 3. 根据所问事的情况找相对应的卦数直接起卦读

主卦、互卦、变卦都可以读。也可以用上下卦相加或相减之后再直读所得的数。
