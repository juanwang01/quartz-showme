## 例187：丢掉解灾物车灾照发生

> **背景**: 武总的帕萨特车2002年购买
>
> **事件**: 车号8573

**起卦**: 《风泽中孚》之《山泽损》

**断卦分析**:
- 兑金克巽木，有撞车信息
- 互卦震木克艮土，今年午火之年土旺木衰
- 明年未年土金旺，木弱无防
- 申酉年金旺，肯定不利

**化解方法**: 买一个米老鼠的玩具放在车前挡风玻璃下边

**结果**:
- 一年多后车一直安全，因玩具脏了被扔掉
- 2004年农历3月，车在高速路上方向盘失控，撞到路边路肩
- 车几乎报废，修车花费10万元，修了4个月

> **教训**: 化解物不可随意丢弃，否则灾难仍会降临

# 第十三节 梅花新易预测电话号码

## 概述

一个人的手机号、车牌号、工号、房间号，甚至偶尔坐火车的一个座位号等等，一切号码都储存了主人的部分信息。

> **看似偶然，实则必然**

### 起卦方法

| 类型 | 方法 |
|:---|:---|
| 手机号 | 一律用后四位起卦 |
| 前两位 | 之和为上卦 |
| 后两位 | 之和为下卦，大于8者用8除，余数作卦 |
| 四数之和 | 除以6，余数作动爻 |

# 第十四节 梅花新易预测生产

## 预测原则

测生产，以体卦为母亲，用卦为婴儿。

| 关系 | 结果 | 条件 |
|:---|:---|:---|
| 体卦用卦相生 | 母子平安 | 体卦用卦在日月临旺相 |
| 体卦克用卦 | 不利于子 | 体卦旺用卦衰：难产或体弱 |
| 体卦克用卦 | 无妨 | 体卦衰用卦旺 |
| 用卦克体卦 | 不利于母亲 | 用卦旺体卦衰：母亲有难或剖腹产 |
| 用卦克体卦 | 无妨 | 体卦旺用卦衰 |

> **重要提示**: 不要用此法为怀孕的人预测生男生女，避免造业

# 第十五节 梅花新易断外应

# 第十六节 梅花新易一卦多断

## 概述

> **任何卦都可以一卦多断**

不但断一个人的卦可以一卦多断，即使一个家庭的电话号码起的卦，就用这一个卦断他全家人，包括每个人的身体状况、流年大运、婚姻等等都很准确。

## 飞宫寻六亲

以体卦为中心：

| 关系 | 含义 |
|:---|:---|
| 我生者 | 子孙 |
| 生我者 | 父母 |
| 克我者 | 官鬼 |
| 我克者 | 妻财 |
| 比肩者 | 兄弟 |
