# 第八节 梅花新易预测官司（续）

## 例145：你丈夫已经进去了

> **背景**: 2008年8月5日己未丁丑（申酉空）
>
> **事件**: 三位年轻女子问事

**起卦**: 报数9、6、18，起卦《天水讼》之《泽水困》

**断卦内容**:
1. 你们是不是告上官司了？
2. 你现在处境是为财的事艰难，摆脱不了困境
3. "兄弟爻持世被动爻戌土发动收入墓库，你丈夫已经进去了，是为财的事情进去的"
4. 钱数是4或9
5. 子孙为执法部门，戌为警察，你丈夫是栽倒在警察手里了

**结果**:
- 她说："是4万，可是我丈夫也没拿"
- 我说："不对，你丈夫拿了2万"
- 她一听很吃惊地说："我丈夫帮别人一个忙，第三者要好处费4万。我丈夫留下一万五千作为来人在北京的吃住用"
- 她说："真是一言难尽，我们白养了那个警察两年，他却借奥运会期间害了我们，真是心狠手毒呀！"

# 第九节 梅花新易预测出行及行人走失

## 测出行

出行，以体卦为自己，用卦为所去之所

| 体用关系 | 结果 |
|:---|:---|
| 用卦生体卦 | 出行顺利，甚至有意外之财，或者多得别人的帮助 |
| 体卦用卦比和 | 出行顺利 |
| 用卦克体卦 | 出行不顺，还容易有灾祸或者不顺心的事情发生 |
| 体卦生用卦 | 出门耗费大，花钱多，或者想办的事情办不成 |

---

## 测行人

以体卦为主

| 体用关系 | 结果 |
|:---|:---|
| 用卦生体卦 | 人容易回来，而且应期快 |
| 体卦克用卦 | 行人能回，但是归期迟 |
| 用卦克体卦 | 行人被住不归或者有灾 |
| 体卦生用卦 | 行人难回，如果体卦在日月旺相，人仍然可以回，只是应期慢 |

---

# 第十节 梅花新易预测失物

测失物，以体卦为主，用卦为失物

| 体用关系 | 结果 |
|:---|:---|
| 体卦克用卦 | 用卦生体卦失物可以找回 |
| 用卦克体卦 | 失物难找回 |
| 体卦用卦比和 | 失物容易找回 |

用卦也可以代表失物的性质，失物的方向，失物的场所，失物的形状及颜色。还要根据对体卦的生克比和关系确定失物能否找回。

# 第十一节 梅花新易预测饮食

占饮食：占饮食用卦生体卦饮食丰盛。一般来说是不分体卦用卦的。只根据卦的八卦万物类象分析对照就可以了。

# 第十二节 梅花新易预测车牌号码

近年来，人民生活水平不断提高，生活节奏不断加快，汽车不再是高不可攀的消费品，正逐步进入寻常百姓家，成为人们快捷的交通工具。汽车给大家带来出行便利的同时，也加剧了交通的拥堵，引发交通事故直线上升，据有关部门统计，每年死于车祸的人数在8万人。交通事故给国家造成严重的经济损失，也给很多家庭带来悲痛和烦恼。

我曾经用车牌号测吉凶的方法是：不看英文字母部分，只把车牌号的数字分成前后两部分，前一组数相加除以8余数为上卦；后一组数相加除以8余数为下卦；两组数相加除以6余数为动爻。

## 车卦部位对应表

| 八卦 | 对应部位 |
|:---:|:---|
| 乾 | 车头、为方向盘、为车顶 |
| 艮 | 制动系统；刹车系统 |
| 震 | 车头、轮胎，也可看做发动机、音响 |
| 巽 | 各类管路、同时还代表车门、排气系统、车内空调 |
| 离 | 发动机、发电机、车灯、电路系统 |
| 坤 | 车身、底盘、车厢内部 |
| 兑 | 齿轮及机械部分、也可看成排气系统 |

## 例176：此车车门有毛病

> **背景**: 2004年冬天，北京下了一场大雪，天气很寒冷。我组织了几位北京的易学爱好者在我家聚会，大家一起交流梅花新易的学习心得。晚上七点左右，大家聊得很开心，忽然一位姓王的朋友提到他新买的车有些问题。王先生四十多岁，在北京一家国企做管理工作，开的是一辆黑色桑塔纳轿车。他有些疑惑地说："我这车买了快一年了，最近发现车门有些毛病，开关不太灵便。我去了好几次修理厂都没查出什么问题。您是学易的，能帮我看看是哪的问题吗？"说完他报出了车牌号：0788。
>
> **事件**: 一位易友王某报出他的车牌号0788，让他帮他看看

**起卦**: 按号起卦《山地剥》之《风地观》

**断卦内容**:
1. 你的车门有毛病
2. 你人随和朴实，人缘好，胆小，或家里有人胆不好。老婆是男人性格
3. 你的车有小的刷蹭，都是别人碰你，都无大碍

**结果**:
- 他说："大姐您说的没错，我的车就是车门有毛病"
- 后来他爱人也做了胆切除手术
