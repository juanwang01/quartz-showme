# 贾双萍《梅花新易》方法论体系

> 来源：《梅花新易》(中国商业出版社, 2009)、2009年面授班笔记、《六爻梅花卦例精解》
> 本文档为梅花易数 AI 断卦系统的权威参考，所有算法和 Prompt 设计均以此为准。
> 相关：[[梅花易数程序设计/梅花易数]]

## 一、核心理念

| 理念 | 说明 |
|------|------|
| **还易于民，道济天下** | 化繁为简，让普通人能学会 |
| **法无定法，我心为法** | 灵活运用，不拘泥死板规则 |
| **周易要符合生活之理** | 断卦必须合情合理，不能脱离常识 |

---

## 二、卦象结构

```
起卦 → 主卦（本卦）→ 互卦 → 变卦
         ↓              ↓       ↓
       当前局面      中间过程  最终结果
```

- **主卦（本卦）**= 当前状态，体用两方现在的态势
- **互卦** = 中间转折、介入的第三方、意外事件
- **变卦** = 最终走向和结局

**时间框架**：

| 层次 | 代表 | 说明 |
|------|------|------|
| 本卦（体用） | **现在** | 当前局势。体卦=卦主当前，用卦=对方/事情当前 |
| 互卦 | **变化过程** | 中间转折、介入第三方、意外事件 |
| 变卦 | **最终结果** | 最终走向。体卦不变（卦主本质不变），变用卦=对方/事情变化 |

## 三、体用学说（六大关系）

| # | 关系 | 含义 |
|---|------|------|
| 1 | **体用分辨** | 动爻所在卦为**用卦**，不动之卦为**体卦**。体卦代表卦主自身 |
| 2 | **体用相生** | 用卦生体卦 → 大吉，外部环境助我 |
| 3 | **体用帮扶** | 同类五行之间相互辅助增强 |
| 4 | **体用相克** | 分两种：体克用(我掌控，可成但迟缓) vs 用克体(受制，凶险) |
| 5 | **体用比和** | 五行相同 → 和谐顺利。**唯一例外：婚姻中比和反易婚变** |
| 6 | 体生用 | 泄气耗散，自身付出多，难成 |
| 7 | 用克体 | 受外部克制，凶险，易有灾祸 |

---

## 四、断卦五大原则

| 关系 | 判断 | 说明 |
|------|------|------|
| **用生体** | ✅ 能成 | 最为吉利，事半功倍 |
| **体克用** | ✅ 能成 | 可成但耗时较长，需付出努力 |
| **体用比和** | ✅ 能成 | 顺遂（婚姻例外，比和反易婚变） |
| **体生用** | ❌ 不成 | 泄体之气，自身消耗，难成 |
| **用克体** | ❌ 不成 | 凶险，易有灾祸 |

## 五、日月旺衰体系（贾双萍最大创新）

### 5.1 核心原则

> "有人认为梅花易数不看日月、不看旺衰，只要用生体就以吉断。这种理论有偏差。物极必反，旺极必然走向反面。"

- **必须日月双看**：月支 + 日支，两者都对体卦旺衰有影响
- **月支主"以前"**的态势（已发生的）
- **日支主"以后"**的走向（将要发生的）
- **日月权重**：日月之爻 > 动变之爻 > 静爻

### 5.2 旺相休囚死（月令定旺衰）

以月令地支为基准，判定各五行旺衰状态：

| 月令地支 | 旺 | 相 | 休 | 囚 | 死 |
|----------|-----|-----|-----|-----|-----|
| 寅、卯（春） | 木 | 火 | 水 | 金 | 土 |
| 巳、午（夏） | 火 | 土 | 木 | 水 | 金 |
| 申、酉（秋） | 金 | 水 | 土 | 火 | 木 |
| 亥、子（冬） | 水 | 木 | 金 | 土 | 火 |
| 辰戌丑未（四季） | 土 | 金 | 火 | 木 | 水 |

**旺衰分数**：旺=5、相=4、休=2、囚=1、死=0

**日支二级调整**：
- 日支生体 → +1.0 分
- 日支与体比和 → +0.5 分
- 日支克体 → -1.0 分
- 体生日支(泄) → -0.5 分
- 体克日支(耗) → -0.5 分

### 5.3 过旺反断

**触发条件**：体卦受用卦生 + 受月支生 + 受日支生 → **过旺**（≥3重生体）

> 过旺反而不成！需要被克泄才能成功。

**案例**：乙酉月丁酉日得《泽山咸》，兑金为体。月酉金生体 + 日酉金生体 + 用艮土生体 → 三重生体 → 过旺 → 结果事情不成。

**反断逻辑**：旺而被克泄反成功。卯月卯日得《离为火》之《火山旅》，体卦离火太旺，被克泄反而成功。

### 5.4 过衰不废

**触发条件**：体卦受日月克泄 + 受用卦克泄 → **过衰**（≥3重克泄）

> 过衰也不代表一事无成！等到得生助之时也可成。

### 5.5 太岁权重

| 太岁与体卦关系 | 断语 |
|---------------|------|
| 太岁生体 | 有进益之喜 |
| 太岁泄体 | 有花钱之事 |
| 太岁克衰体 | 有灾 |
| 太岁克旺体 | 升官/工作调动 |
| 太岁与体比和 | 平安之年 |
| 旺体克太岁 | 有大财 |

## 六、入墓体系

### 6.1 五行墓库

| 五行 | 墓库地支 |
|------|----------|
| 金 | 丑 |
| 木 | 未 |
| 水 | 辰 |
| 土 | 辰 |
| 火 | 戌 |

### 6.2 入墓吉凶

> **旺体入墓 → 无妨；衰体入墓 → 有灾**

**案例**：《坤为地》之《雷地豫》，变卦震为小孩，逢2003年未年（木入墓于未），断小孩该年死亡。

### 6.3 入墓应期

入库/入墓 → 逢冲（冲墓库）或临值（值墓库地支）之时为应期。

## 八、应期方法

### 8.1 核心规则

| 爻的状态 | 应期在 |
|----------|--------|
| **动爻** | **逢值**（临值）、**逢合** 之时 |
| **静爻** | **逢值**、**逢冲** 之时 |
| **破爻**（月破/日破）| **临值**、**逢合**、**逢冲** 之时 |
| **入库/入墓** | **逢冲**（冲墓库）或 **临值** 之时 |

### 8.2 主应期层级

| 动爻位置 | 应期层级 | 说明 |
|----------|----------|------|
| 初爻、二爻 | 时辰/日 | 应期较快，逢值逢合在数日内 |
| 三爻、四爻 | 日/月 | 应期适中，逢值逢合在数日到数月 |
| 五爻、上爻 | 月/年 | 应期较长，逢值逢合在数月到数年 |

### 8.3 特殊应期

- **近病**：逢冲则愈，逢合则死
- **久病**：逢合则愈，逢冲则死

### 8.4 六爻取数体系

| 地支 | 数字 |
|------|------|
| 亥、子 | 1、6 |
| 寅、卯 | 3、8 |
| 巳、午 | 2、7 |
| 申、酉 | 4、9 |
| 辰、戌、丑、未 | 5、10 |

### 8.5 流年应期（太岁维度）

- 太岁生体之年 → 进益
- 太岁泄体之年 → 破财
- 太岁克衰体 → 有灾
- 旺体克太岁 → 大财
- 体入墓之年 → 旺体无妨，衰体有灾

### 8.6 全量时间槽

应期推算覆盖四个时间维度的全量槽位，每个槽位标注：
- **逢值**：地支 = 动爻地支
- **逢合**：地支 = 动爻地支的六合
- **逢冲**：地支 = 动爻地支的六冲
- **入墓**：地支 = 体卦五行墓库
- **冲墓**：地支 = 墓库的六冲
- **有利**：地支在体卦有利列表中
- **不利**：地支在体卦不利列表中

| 维度 | 数量 | 起算方式 |
|------|------|----------|
| 时辰 | 12 个 | 五鼠遁，日干起时干 |
| 日期 | 30 天 | 日柱逐日推进 |
| 月份 | 12 月 | 五虎遁，年干起月干 |
| 年份 | 12 年 | 年柱逐年推进 |

## 九、直读法（三大直读）

### 9.1 数字直读
上下卦直接读出数字。例：《山地剥》艮7坤8 → 78/87；《火泽睽》离3兑2 → 23/32。

### 9.2 卦象直读
直接从卦象读出事物特征。例：离=文凭/眼睛/火/红色，兑=口/说/缺/破损。

### 9.3 卦名直读
用卦名直接判断。例：
- 天地否 → 否定、不通
- 山地剥 → 摔落、失败、剥落
- 水风井 → 被困、停滞
- 火水未济 → 事未成
- 火泽睽 → 瞪眼、争吵、分歧

## 十一、六亲体系（飞宫寻六亲）

借鉴六爻纳甲，引入六亲概念到梅花断卦。以体卦五行为"我"来定六亲：

| 六亲 | 五行关系 | 代表 |
|------|----------|------|
| **父母** | 生我者 | 文书、房屋、长辈、学业 |
| **兄弟** | 同我者 | 朋友、同事、竞争、平辈 |
| **官鬼** | 克我者 | 官职、疾病、官非、丈夫(女测) |
| **妻财** | 我克者 | 钱财、妻子(男测)、财富、资产 |
| **子孙** | 我生者 | 子女、下属、娱乐、宠物 |

## 十二、外应断事

- **不要刻意求外应**，无意中碰到的才准
- 外应优先级很高，可直断其事
- "周易的道理要符合生活之理"

## 十三、解灾方法

- 用**地支通关**化解五行相克：火水相克 → 用木通关（在南边放兔等属木之物）
- 木土相克 → 用火通关
- 解灾前需先**放生**
- 解灾物**不能与事主生肖相冲克**

## 十四、一卦多断 & 多卦一断

- **一卦多断**：同一卦可同时看婚姻、事业、健康、六亲，信息全方位展开
- **多卦一断**：同一件事用多个卦交叉验证
- **六爻与梅花同断**：一事一断时以起卦方式决定主法；一卦多断时两法互验

**一卦多断叠加规则**：
- 本卦·体 = 卦主现在的状态（性格/外貌/心态/处境）
- 本卦·用 = 对方/事情现在的状态
- 互卦 = 过程中出现的变数/介入方/转折
- 变卦·体 = 卦主最终状态（同一体卦，本质不变）
- 变卦·用 = 对方/事情最终的状态

## 十五、完整断卦流程（10步）

```
Step 1  起卦       → 得主卦、互卦、变卦
Step 2  定体用     → 动爻所在为用，不动为体
Step 3  看日月     → 月支+日支对体卦的生克旺衰影响
Step 4  看生克     → 体用五大原则判断基本吉凶
Step 5  过旺过衰   → 是否触发反断（过旺不成、过衰不废）
Step 6  看入墓     → 体卦五行是否入月/日/年支墓库
Step 7  直读       → 卦名直读 + 卦象直读 + 数字直读
Step 8  取象       → 万物类象落到具体人事，一卦多断
Step 9  定应期     → 动爻逢值逢合 / 静爻逢值逢冲 / 入墓逢冲临值
Step 10 综合判断   → 吉凶结论 + 应期 + 建议 + 解灾方案
```

## 十六、对 AI 断卦的 Prompt 设计指导

### 设计原则

1. **固定推理链路，不可乱改**：AI 必须严格按 10 步流程断卦
2. **本地计算先行**：卦象推演、干支历法、旺衰应期全部本地完成，AI 只做解读
3. **结构化输入**：AI 接收的是完整的本地计算结果（时间坐标 + 卦象 + 旺衰 + 全量时间槽）
4. **纯文本输出**：不要 JSON，按 8 板块模板输出自然语言

### Prompt 必须包含的数据

- 起卦时间（公历 + 农历 + 四柱 + 月令 + 节气区间）
- 卦象信息（本卦/互卦/变卦/上下卦名称/体用判定）
- 五行生克（原用卦分析/变用卦分析/互卦分析/综合结论）
- 日月旺衰（体卦+各用卦的旺衰状态/日支影响/入墓/过旺过衰/太岁）
- 应期数据（动爻地支/逢值逢合逢冲/墓库/全量时间槽66条带标记）
- 八卦万物类象速查表（让 AI 取象时落在具体人事上）
- 六亲体系（飞宫寻六亲参考）

### AI 输出模板（8 板块）

```
🔮 卦象解读    — 卦名直读、卦象直读、数字直读
👤 现状核验    — 从卦象反推求测者当下状态、场景、心境
⚖️ 吉凶判断    — 一个字：吉/凶/平 + 解释
🔥 旺衰分析    — 体卦+各用卦旺衰，过旺过衰是否触发，入墓情况
🔄 过程推演    — 互卦揭示的中间转折、介入方、意外事件
🏁 结果预测    — 变卦揭示的最终走向，各方最终状态
⏰ 应期判断    — 逢值逢合的具体时间窗口
💡 应对建议    — 具体可操作的行动方案，含通关解灾方法
```
