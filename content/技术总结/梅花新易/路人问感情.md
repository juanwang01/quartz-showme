## 二、冲突判断：卦大象义压倒体用生克

> 此为「卦大象义 vs 体用生克」冲突的典型卦例，参照[[技术总结/梅花新易/卦辞与生克冲突辨析]]方法论处理。

### 2.1 体用生克层面的"吉"（表象，应舍弃）

| 关系    | 生克       | 常规断法      |
| ----- | -------- | --------- |
| 本卦用生体 | 坤土生乾金    | 用生体 → 大吉  |
| 变卦用生体 | 艮土生乾金    | 用生体 → 大吉  |
| 月令    | 午火克体（金囚） | 大吉折损 → 小吉 |
|       |          |           |

若按纯体用生克断，结果应为"吉"，顶多因金囚降为小吉。

### 2.2 卦大象义层面的"凶"（真相，应取为断卦根本）

| 卦    | 大象义                | 对应感情      |
| ---- | ------------------ | --------- |
| 天地否䷋ | **天地不交、阴阳阻隔、闭塞不通** | 心意隔绝，感情不通 |
| 天山遁䷠ | **退避隐退、抽身远遁、大势已去** | 关系终结，各自退散 |

### 2.3 冲突规则适用

参照邵雍《卦断遗论》原文规则：

> **凡占卜决断，固以体用为主，然有不拘体用者。**
> **例：占西林寺额，得山地剥卦，体用互变五行全比和，按生克本应大吉；但断为大凶。何故？寺为纯阳僧人居所，剥卦群阴剥阳，卦大象义理极凶，此时舍体用生克，专取卦义断。**

**此卦与之同类：**
1. 否卦 — 群阴闭阳、天地不通，卦义极凶（堪比剥卦的"群阴剥阳"）
2. 遁卦 — 退避隐藏、大势已去，卦义亦然
3. 所求之事（感情坎坷）完全贴合否卦的"闭塞不通"和遁卦的"退避抽身"大义
4. 体用生克的全然"用生体"与卦义严重冲突

→ **结论：舍体用生克，专取卦义断。此卦应以"凶"为根本定调。**

### 2.4 体用生克的剩余价值（仅作情景参考）

舍掉体用生克作为吉凶判断后，体用生克的信息仍可作**情景补充**：
- 坤土艮土生乾金 → 对方虽最终选择退避，但对卦主无恶意、无撕破脸、无仇恨
- 全局无克体 → 分开过程平顺，不会爆发激烈冲突，是"默默疏远"而非"吵翻决裂"

这是体用生克在此冲突场景中唯一能用的信息——**描述过程温和与否，而非判断吉凶成败**。

## 三、本卦天地否 现状解读

否卦大象：天地不交、阴阳阻隔、情志闭塞，上下不通之象。

1. **感情现状对应**：感情运势长期昏暗不通，难遇真心契合之人。即便有接触机会，也多是表面来往、心意无法互通，付出多回馈少，越主动越耗竭。
2. **卦象性格**：乾为刚健金，卦主性格强势、主见重、不喜低头；坤为柔顺土，对方或过往感情对象偏温和迁就，但长期失衡，对方最终也会收回包容。
3. **闭塞根源**：否卦天地不交的核心在于"双方不在同一个频道上"。卦主心气高、不愿妥协，而感情需要阴阳相交才能疏通——这正是否卦的死穴，越主动越堵塞，越想要越拿不到。

## 四、变卦天山遁 后续趋势解读

坤土动化艮山，艮为止、为阻隔、为收敛退避；遁卦本义：抽身隐退、大势已去。

1. **关系走势**：否卦不通在前，遁卦退散在后。感情上升通道已断，不再是"暂时搁置、等待时机"，而是**缘分通道关闭、各自退回到各自生活轨道**。
2. **艮为止的核心**：动爻坤变艮，代表对方从柔顺包容转向自我封闭保护，不再敞开。不是赌气冷战，而是心门已关、无意再续。
3. **遁卦的定性**：遁为退避，不是暂时止步，而是**战略性撤退**——在感情上就是缘分走到尽头、各走各路。与"需要等待时机再续"有本质区别。

> 「否」已闭塞不通，「遁」再补一刀退避抽身，两卦联动，卦义极其清晰：此路不通，及时止损。

## 五、卦象应验反馈

卦主反馈：感情确如卦象所示一路坎坷。天地否的闭塞让人困在其中走不出来，天山遁之后逐渐放下，虽无激烈争吵，但缘分确实走到了头。

1. **天地否闭塞不通** ✅：长期感情不顺，心意不达
2. **天山遁退避抽身** ✅：最终各自退散，缘分通道关闭
3. **体用生克"用生体"的残余信息** ✅：整个过程没有撕破脸、没有仇恨，平顺收场
4. **核心验证**：若当初按体用生克断"小吉、等待时机可复合"，则完全错判——卦象的本质是否通+遁散，不是"等待"而是"结束"

## 六、综合总结与反思

### 6.1 本卦正确断法

| 维度 | 结论 |
|------|------|
| **根本判断** | **凶**（否+遁，卦义极凶，舍生克） |
| **感情定性** | 闭塞不通→退避抽身，缘分走到尽头 |
| **过程形态** | 平顺疏远，无激烈冲突（体用生克的残余信息） |
| **行动建议** | 及时止损、不可强求，遁卦宜退不宜进 |

### 6.2 经验教训：断卦必须优先看卦名

本卦例是**踩坑后反思**的典型案例——当初被"用生体"的体用生克迷惑，断成了"吉（小吉），需等待时机"，与实际情况完全不符。

教训：
1. **断卦第一步永远先看卦名**：否、遁、剥、明夷、大过、睽等卦名自带极强吉凶定数，优先级最高
2. **体用生克只在卦大象义无强烈倾向时才做主**：如果卦名本身已经讲了一个极其明确的故事，不要被生克数字迷惑
3. **冲突时参照《卦断遗论》"舍体用生克，专取卦义断"**：西林寺剥卦的体用比和大吉断为大凶，与此卦同例
