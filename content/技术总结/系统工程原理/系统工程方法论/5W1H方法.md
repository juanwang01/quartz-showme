# 一、核心定位
 
- 本质：结构化问题分析与决策工具，通过6个维度全覆盖思考，避免片面性
- 核心价值：厘清逻辑、明确边界、落地可执行，适用于从问题诊断到方案制定的全场景
- 核心逻辑：先定“为什么做”，再明确“做什么”，最后落地“怎么干”
 
# 二、六大维度（按逻辑顺序梳理）
 
1. Why（为何）—— 目标与价值
 
- 核心问题：为什么要做？核心价值是什么？不做的后果？
- 关键作用：对齐共识、论证必要性、化解抵触情绪
- 实操要点：答案要聚焦“核心价值”，避免空泛（例：不是“优化服务”，而是“降低客户投诉率30%”）
 
2. What（何事）—— 任务与交付物
 
- 核心问题：要做什么具体事？核心成果（交付物）是什么？边界在哪里？
- 关键作用：界定范围、明确目标，避免执行中“跑偏”
- 实操要点：明确“做什么”和“不做什么”，交付物要具体可衡量（例：不是“做活动”，而是“策划一场300人线下产品发布会，产出10篇媒体报道”）
 
3. Who（何人）—— 权责与参与方
 
- 核心问题：谁牵头？谁执行？谁受益？谁监督？谁配合？
- 关键作用：明确权责、避免责任真空，确保协作顺畅
- 实操要点：每个角色对应具体职责，不模糊（例：不是“团队负责”，而是“张三牵头方案设计，李四负责资源协调，王五监督进度”）
 
4. When（何时）—— 时间与优先级
 
- 核心问题：何时启动？何时完成？关键里程碑是什么？各环节优先级？
- 关键作用：管控进度、合理分配时间，避免拖延
- 实操要点：时间节点明确到具体周期/日期，区分核心与次要任务（例：不是“下个月完成”，而是“5月10日前完成方案初稿，5月20日前定稿”）
 
5. Where（何地）—— 地点与范围
 
- 核心问题：在哪里做？执行范围是什么？环境有什么约束？
- 关键作用：确定场地、规避环境风险，明确影响边界
- 实操要点：结合场景考虑约束（例：不是“在公司做”，而是“在公司3号会议室开展培训，需提前确认设备兼容性”）
 
6. How（如何）—— 方法与资源
 
- 核心问题：具体怎么做？步骤是什么？需要哪些资源（人/财/物）？风险怎么应对？
- 关键作用：落地执行、规避风险，确保方案可行
- 实操要点：步骤拆解到“可直接动手”，资源与风险提前规划（例：不是“做好推广”，而是“通过抖音+小红书投放，预算5万元，提前准备3套备选文案应对审核风险”）
 
# 三、核心原则
 
1. 全面性：6个维度缺一不可，避免遗漏关键信息
2. 逻辑性：严格遵循“Why→What→Who→When→Where→How”顺序，不颠倒
3. 可量化：每个维度答案尽量具体、可衡量，拒绝模糊表述
4. 迭代性：信息完善后可动态修正，适配场景变化
 
# 四、典型应用场景
 
- 问题诊断：分析生产异常、客户投诉、项目延期等根源
- 计划制定：项目规划、活动策划、产品研发、学习计划
- 流程优化：梳理工作/服务/生产流程，消除冗余
- 沟通汇报：会议议程、项目汇报、方案提案（让表达更清晰）
 
# 五、工具融合技巧
 
- 搭配WSR：用5W1H细化物理（技术约束）、事理（流程步骤）、人理（参与方）
- 搭配SSM：用5W1H梳理丰富图中的利益相关者、行动节点
- 搭配霍尔三维：用5W1H明确时间维（节点）、逻辑维（步骤）、知识维（参与人）
 
# 六、快速记忆口诀
 
Why定价值，What明任务，Who划权责，When控时间，Where锁场地，How落地执行
