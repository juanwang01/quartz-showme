# 核心方法论定位
 
1. SSM（软系统方法论）：聚焦结构不良、目标模糊、多方利益冲突的软问题，核心是通过多元视角与迭代学习，构建共识与可行方案。
2. 霍尔三维模型：聚焦结构良好、目标明确、技术路径清晰的硬系统/工程项目，核心是线性结构化阶段管控，保障按时按质交付。
3. WSR（物理-事理-人理）：聚焦技术+人文复合的复杂系统问题，核心是三维协同（客观规律+流程方法+人际协同），实现整体最优与落地共识。
4. 5W1H（六何分析法）：通用结构化分析工具，核心是通过六个维度（Why/What/Who/When/Where/How）全面拆解问题、厘清需求，适配全场景的快速分析与方案细化。
 
# 核心运用时机与典型场景
 
SSM（软系统方法论）
 [[软系统方法论]]
- 核心时机：项目前期·问题定义/共识构建阶段（无统一问题定义、情绪化对抗、利益诉求差异大）
- 典型场景：社区治理（加装电梯、垃圾分类）、组织变革（部门重组、跨部门协作）、公共服务优化（医疗资源分配）、创新项目前期（新产品需求探索）
- 关键触发点：目标模糊、边界不清、多方对立、无成熟方案
 
霍尔三维模型
 [[霍尔三维结构]]
- 核心时机：项目中期·方案执行/阶段管控阶段（目标量化、技术方案确定、需分阶段验收、预算固定）
- 典型场景：大型基建工程（桥梁、水利、轨道交通）、IT系统实施（ERP、工业软件）、标准化生产/流程再造（生产线升级）
- 关键触发点：需求固化、步骤清晰、有明确交付物、需严格进度/成本/质量管控
 
WSR（物理-事理-人理）
 [[物理-事理-人理方法论（WSR）]]
- 核心时机：项目全生命周期·尤其方案设计+协调实施阶段（物理约束明确、事理流程需优化、人理矛盾突出，三者相互影响）
- 典型场景：智慧城市（充电桩、智慧社区）、大型工程项目管理（新能源电站、机场建设）、企业数字化转型（制造业升级）、公共危机治理（疫情防控）
- 关键触发点：技术与人文并重、需兼顾可行性与合意性、多维度矛盾交织
 
5W1H（六何分析法）
 [[5W1H方法]]
- 核心时机：全场景·快速分析/方案细化/沟通汇报阶段（任何需要厘清逻辑、明确边界、落地执行的环节）
- 典型场景：问题诊断（生产异常、客户投诉）、计划制定（活动策划、学习计划）、流程优化（工作/服务流程）、沟通汇报（会议议程、项目汇报）
- 关键触发点：需要快速拆解问题、梳理方案、清晰表达，适配其他方法论的细化落地
 
# 选型与组合应用建议
 
1. 单一选型
- 纯软问题、共识缺失 → SSM
- 纯硬项目、执行管控 → 霍尔三维模型
- 技术+人文复合、三维协同 → WSR
- 快速拆解、细化方案、沟通汇报 → 5W1H
2. 组合应用（复杂项目最优解）
- 老旧小区充电桩项目：SSM（前期共识）→ WSR（三维方案设计）→ 5W1H（细化执行）→ 霍尔三维（分阶段管控）
- 企业数字化转型：SSM（诉求共识）→ WSR（技术+流程+组织协同）→ 5W1H（细化计划）→ 霍尔三维（实施验收）
3. 切换时机
- SSM→WSR：达成初步共识后，进入三维方案设计
- WSR→5W1H：方案框架确定后，细化执行步骤与权责
- 5W1H→霍尔三维：执行计划固化后，进入标准化阶段管控
