项目概述

梅花易数 AI 断卦系统 — 基于贾双萍《梅花新易》方法论的完整软件实现。定位为干支逻辑计算器 + AI 专业断卦，已完成 CLI 命令行工具 + Flet 手机 UI 双模式。

项目路径：E:\xiangmu\meihua 当前版本：CLI v1 + UI v4（2026-06-07）

一、核心设计理念

三大原则

  1. 卦源必须用户现实获取（数字起卦 / 手动选卦 / 时间起卦），程序不做 AI 自动起卦
  2. 程序只做：计算、解析、推演、AI 分析、存储
  3. AI 分工：Claude 负责提示词体系、逻辑规范、架构设计；DeepSeek 负责 APP 运行时 AI 推理

设计哲学

不是一个花里胡哨的多媒体软件，而是一个极其敏锐的干支逻辑计算器——把旺衰、生克、入墓、应期这些真正决定断卦准确度的逻辑做到极致。

二、技术架构

整体四层架构

层级技术职责
UI 界面层Flet (Python, v0.24.1)手机端三页面：起卦 / 展示+追问 / 历史
业务算法层纯 Python 核心卦象推演、干支历法、旺衰应期
AI 推理层DeepSeek API (OpenAI 兼容)10步断卦、追问对话
数据持久层SQLite本地卦例库，24+ 条记录

技术栈定稿

  • 前端/移动端：Flet 0.24.1（浏览器模式，http://localhost:8555）
  • 后端逻辑：原生 Python 3.12（venv）
  • 本地数据库：SQLite（data/meihua.db）
  • AI 模型：DeepSeek Chat API
  • 干支历法：lunar-python ≥1.4.0

三、项目模块详解

模块 1：卦象录入（三种方式）✅ 已实现

方式说明
手动选卦下拉框选择上卦(1-8)、下卦(1-8)、动爻(1-6)
时间起卦上卦=小时%8, 下卦=分钟%8, 动爻=(小时+分钟)%6，自动获取四柱
数字起卦输入三个任意数字，自动取模计算 + 支持随机生成

模块 2：梅花核心推演算法 ✅ 已实现

文件：meihua/core/calculator.py（~732行）

  • 先天八卦数映射：乾1兑2离3震4巽5坎6艮7坤8
  • 64卦完整数据库映射（(上卦名, 下卦名) → (卦名, 卦画)）
  • 自动计算：本卦、互卦（二三四→下互、三四五→上互）、变卦（动爻阴阳反转）
  • 体用判定：动爻 1-3→下卦为用、4-6→上卦为用
  • 五行生克分析：体 vs 原用 / 体 vs 变用 / 体 vs 互卦 / 综合吉凶结论
  • 输入容错：卦数取模（>8 自动映射）、变爻取模（>6 自动映射）

模块 3：干支历法 + 节气月令 ✅ 已实现

文件：meihua/core/time.py（~392行）

  • 完整四柱干支：年柱（立春为界精确到小时）、月柱（节气换月）、日柱、时柱（五鼠遁）
  • 节气月令判定：基于 lunar-python 精确节气计算，非农历月份
  • 真太阳时转换：均时差 + 经度修正，支持 20+ 中国城市
  • 时间全量列表：时辰(12)、日期(30天)、月份(12月)、年份(12年) — 全部带干支
  • 年柱修正：立春时刻前仍属上一干支年，自动判定

模块 4：旺衰体系 + 应期推算 ✅ 已实现

文件：meihua/core/wuxing.py（~717行）

这是整个项目的核心算法难点，基于贾双萍《梅花新易》方法论：

日月双看定旺衰：

  • 月令为主：定旺相休囚死（5/4/2/1/0 分制）
  • 日支为辅：生体+1分、比和+0.5分、克体-1分、泄体-0.5分
  • 过旺反断：体得月+日+用卦多重相生（≥3重）→ 反而不成
  • 过衰不废：体受月+日+用卦多重克泄（≥3重）→ 得生可成

五行入墓体系：

  • 金墓丑、木墓未、水土墓辰、火墓戌
  • 旺体入墓无妨、衰体入墓有灾
  • 入墓应期：逢冲（冲墓库）或临值

太岁权重：

  • 太岁生体→进益、太岁泄体→破财
  • 太岁克衰体→有灾、旺体克太岁→大财

应期推算（逢值逢合逢冲体系）：

  • 动爻→逢值（临值）、逢合（六合）
  • 静爻→逢值、逢冲
  • 破爻→临值、逢合、逢冲
  • 入墓→逢冲、临值
  • 全量时间槽 66 条标注：逢值/逢合/逢冲/入墓/冲墓/有利/不利

六爻取数：亥子→1,6 / 寅卯→3,8 / 巳午→2,7 / 申酉→4,9 / 辰戌丑未→5,10

模块 5：AI 断卦 ✅ 已实现

文件：meihua/ai/prompts.py（~430行）、meihua/ai/client.py（~129行）

Prompt 设计（贾双萍梅花新易 10 步断卦法）：

  1. 直读法（卦名/卦象/数字直读）
  2. 现在取象（本卦体用 — 万物类象落到具体人事）
  3. 现状核验（反推卦主当前真实场景）
  4. 日月旺衰判断（日月双看 + 过旺过衰 + 入墓 + 太岁）
  5. 体用生克定吉凶（五大原则）
  6. 过程取象（互卦揭示中间转折）
  7. 结果取象（变卦最终走向）
  8. 应期判断（逢值逢合逢冲体系，从全量时间槽选取）
  9. 六亲与外应（飞宫寻六亲，一卦多断）
  10. 应对方案 & 解灾（地支通关法化解）

输出格式：纯文本 8 板块模板（🔮卦象解读 / 👤现状核验 / ⚖️吉凶判断 / 🔥旺衰分析 / 🔄过程推演 / 🏁结果预测 / ⏰应期判断 / 💡应对建议）

API 调用：

  • DeepSeek Chat API（OpenAI 兼容接口）
  • 支持流式输出（--stream）
  • API Key 管理：.env 文件（环境变量） > config.yaml > 交互输入
  • 自动加载 dotenv，Key 不提交 git

模块 6：结构化存储 ✅ 已实现

文件：meihua/storage/models.py（~111行）、meihua/storage/db.py（~142行）

CaseRecord 完整字段（32 个字段）：

  • 唯一 ID（12位 hex）、创建时间
  • 时间坐标：公历、农历、四柱、月令、真太阳时
  • 卦象：本卦、互卦、变卦、动爻、体卦、用卦、体用关系、旺衰、应期级别
  • 用户输入：求测事项
  • AI 字段：现状核验、完整推理链、吉凶、应期结论、应对方案、原始 AI 全文
  • 后续更新：事后真实结果、对话历史(JSON)、标签(JSON)、公开/私有标记

SQLite CRUD：save / get / list / update / delete / count

六、方法论体系

基于贾双萍《梅花新易》（中国商业出版社, 2009）完整实现：

  • 日月双看定旺衰（月令为主 + 日支为辅）
  • 过旺反断（体得月+日+用三重相生 → 反而不成）
  • 过衰不废（体受月+日+用三重克泄 → 得生可成）
  • 五行入墓（金丑/木未/水土辰/火戌，旺体无妨衰体有灾）
  • 逢值逢合逢冲应期（动爻逢值逢合 / 静爻逢值逢冲 / 入墓逢冲临值）
  • 直读法（卦名直读 + 卦象直读 + 数字直读）
  • 万物类象现代化（八卦类象落到现代生活场景）

详细方法论文档：meihua/docs/jia_shuangping_methodology.md
